Documento de contexto:

Estou fazendo um projeto chamado Topfy, que sua premissa é o usuário inserir músicas, formando uma playlist, que o sistema vai fazer o cálculo, e trazer para o usuário informações relevantes, como os 3 artistas mais ouvidos, e o gênero mais predominante de sua playlist.



A plataforma confere cadastro e login de usuários, através de SQL. HTML, CSS e Javascript com JSON para confecção de toda a parte visual e funcional do site. Dentro da plataforma, fará uso de ChartJS para confecção de gráficos para dashboard, e o uso de API da Deezer, para recolher as fotos dos artistas mais ouvidos, auxiliar na busca de músicas, sugerindo baseado na input do usuário, e trazendo um player de música para as músicas de sua playlist.

O projeto não é uma plataforma de player de música, e também não realiza importação de músicas seja MP3, ou seja playlist/músicas do Spotify ou qualquer outra plataforma.

Dentro da plataforma, também haverá um quiz, para recomendação de músicas. Será feito de uma forma parecida com um teste de personalidade, mas para recomendação de músicas de acordo com o perfil de personalidade do usuário.



O usuário realiza o cadastro da música, do artista, e do gênero.
